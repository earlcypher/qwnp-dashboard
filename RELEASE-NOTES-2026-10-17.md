# Dashboard release notes — 2026-10-17

This change set publishes the verified dashboard updates and documentation alongside the backend security release. Historical local-only statements in `FIXES-2026-10-17.md` describe the review stage, not the publication decision.

## Changes

- Removed browser logs of parsed cookies, headers and token prefixes.
- Credential-upload messages distinguish persistent file saves from runtime-only updates on environment-backed deployments.
- Cookie presence is labeled loaded, not proven valid upstream authentication.
- Tier and API documentation now show backend defaults: free 20, premium 60 and enterprise 120 requests/minute, per key/backend process. Environment overrides can change actual policy; displayed numbers are defaults, not live policy data.
- Removed unsupported claims of enforced daily quotas and free-tier model restrictions.
- Added `npm run typecheck` and corrected README Node 22, port 3001, sessionStorage and static-export guidance.
- No dependency versions were upgraded.

## Backend/database compatibility

The paired backend implements `/admin/headers/upload`, accepts the Netscape cookie format generated by this UI, reads refreshed credentials immediately, fails closed on missing Supabase configuration and enforces per-key limits across API/admin/probe calls.

The live Supabase permission migration has already been applied and verified. Browser roles cannot directly access keys/logs/stats or maintenance RPCs; backend service-role access remains available. The dashboard communicates through the proxy using an enterprise proxy key—it must never receive the Supabase service key.

For environment-backed credential saves, update backend `COOKIES_B64`/`HEADERS_B64` deployment secrets manually for restart persistence. The UI upload alone does not update hosted secret settings.

## Publication and operations

The owner authorized pushing all fixes and documentation to `main`, knowing that Vercel/Render automation may run. Git push success does not establish successful production rollout; inspect deployment status separately.

Set `NEXT_PUBLIC_API_URL` to the paired backend's origin. Use the backend's public `/health` for unauthenticated uptime monitoring; `/health/credentials` now requires enterprise authentication and quota.

The formerly embedded proxy admin key was removed from source, not revoked from the database. Coordinate replacement/deactivation separately so operators are not locked out.
